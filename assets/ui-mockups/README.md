这里保存软件化阶段的视觉参考图与中央舞台素材：

- `desktop-ui-concept.png`：桌面端主界面高保真概念图。

- `hero-piano-stage.png`：桌面端中央舞台运行时背景，已由 `App` 加载并绘制。

## 设计语言

- 背景使用深蓝黑 `#0B1019`，内容面板使用 `#121B29`，边框使用低对比度蓝灰。
- 香槟金 `#D7AD68` 只用于主操作、焦点、进度和品牌标识，避免大面积高亮。
- 白键保持象牙白，黑键使用带高光的漆黑；键盘始终是桌面端的视觉中心。
- 面板按“品牌/状态 → 曲目与控制 → 键盘 → 运输与跟练 → 帮助”分层，保证 1100×880 的最小窗口仍可用。

## 落地映射

桌面端设计稿对应现有 raylib 组件：

| 设计区域 | 现有实现 |
|---|---|
| 顶部品牌与状态 | `App::drawTopbar()`、`App::drawHero()` |
| 曲库与筛选 | `App::drawSongPanel()` |
| 右侧音色/音量/混响 | `App::drawControlsRow()` |
| 88 键键盘 | `PianoView` |
| 播放、录制、导出 | `App::drawTransportRow()` |
| 跟练谱面与评分 | `App::drawSongPanel()`、`PracticeJudge` |

安装向导设计稿建议作为后续 CPack NSIS 或独立安装器的页面规范，步骤固定为：

1. 欢迎：产品名称、版本、简短说明。
2. 位置：安装路径、空间需求、桌面快捷方式。
3. 安装：进度、当前文件、取消操作。
4. 完成：启动软件、打开说明、关闭向导。

设计稿中的图片文字用于评审和排版参考，真正的安装器文字应由安装器控件渲染，
避免把交互文字烘焙进位图。中央舞台背景只承载氛围，界面文字、按钮和状态仍由
raylib 控件绘制。
